# Capsule branch

This fork carries the changes [Capsule](https://github.com/louislovni/capsule), an iOS app built on
PokeDaisy's libretro cores, needs. Branch `capsule` = upstream PokeDaisy + these commits; upstream's
`main` is merged in from time to time. Everything here stays under PokeDaisy's GPL-3.0.

- French DS carts in the companion
- DS EXPAND in the libretro core (`third_party/patches/dsperate-capsule.patch` for DSperate's Gpu3D)
- the GBA canvas follows the panel option at runtime (phone rotation)
- Apple-friendly link options
